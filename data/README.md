# Local data

Keep downloaded, processed, and labeled datasets in this directory. Data files are ignored by Git; this README is the only initial tracked file here.

Record source, license, checksum, processing version, and split/group membership in versioned manifests once ingestion exists. Keep secrets and personal message content out of logs and committed documentation. Do not download data as part of an API request or a routine pull-request check.

The initial repository contains no dataset. See [the baseline milestone](../ml/README.md) for the first ingestion task.
